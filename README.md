# pygame_pixeler
## Pygame Custom Pixel Art 
* **A lightweight, easy-to-use codeblock for creating custom pixel art directly inside your Pygame projects without needing external image files.

## Features
* **No External Assets: simple text grids or lists

* **Scalable: scales pixels to fit any window size or zoom level.

* **Custom Colors: map characters/symbols to any RGB color tuple.

* **Lightweight: Built purely on standard Pygame surfaces

## Installation & Setup
* **Simply copy the PixelArt class into your existing Pygame project. No pip installation or extra dependencies are required beyond standard Pygame.
